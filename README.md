# Backend Bienes Raices

El proyecto es una plataforma para poder publicar y vender propiedades.Puedes registrarte, seleccionar los rangos de precio , categoria de la propiedad y subir una imagen de la propiedad, seleccionar en un mapa la ubicacion de la propiedad ,asi como eliminar y modificar.
Esta hecho en su mayoria con Express js ya que se utiliza PUG como platilla para el front-end.
El principal objetivo del proyecto era para mejorar con Express js, ya que las bases se pueden aplicar para otras tecnologias.

pagina del proyecto : https://bienes-raices-2-inky.vercel.app/

### Como utilizarlo:

Primero se necesita los siguiente:

- URL de coneccion a tu base de datos.
- Key ,secreto y nombre de cloudinary.
- Un correo junto a la contraseña para aplicaciones.
- La linea de texto secreta para el auth que se puede generar aqui (https://auth-secret-gen.vercel.app/).

### Tecnologias utilizadas:

- Express js.
- HTML.
- Pug.
- CSS , Tailwind.
- Javascript.
- Sequelize ORM.
- PostgreSQL
- Supabase para la base de datos.

Librerias como:

- Leaflet (para los mapas).
- Auth con jsonwebtoken.
- Cloudinary (plataforma de gestión de imagenes y videos).
- Nodemailer (envio de correos electronicos).
- Express-validator (validador de datos).
